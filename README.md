# 🎓 EduPath — Token-Safe Hybrid Learning Agent

Two-model adaptive learning prototype:

- Qwen 3.8 27B: profile insights, planning, practice, Q&A.
- GPT-OSS 120B: two-stage deep assessment.
- DDGS: web research.
- Python: skill-gap and mastery state updates.
