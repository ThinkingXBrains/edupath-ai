# 🎓 EduPath — Adaptive Learning Companion

A token-safe two-LLM learning agent.

- **Qwen 3.8 27B:** compact profile, planning, practice and Q&A.
- **GPT-OSS 120B:** two-stage deep assessment.
- **Python:** canonical skill mapping, gap calculation, mastery update and progress.
- **DDGS:** web research.

The profile UI owns target role, experience and learning hours, so those values
are not redundantly generated by the LLM.

## Render

Build:
`pip install -r requirements.txt`

Start:
`python app.py`

Secret:
`GROQ_API_KEY`
