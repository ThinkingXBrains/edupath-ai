# EduPath — Adaptive Learning Companion

Two-model adaptive learning prototype with token-aware LLM routing, deterministic learner-state logic, canonical skill mapping, and quality-controlled web research.

Research uses trusted-domain searches and filters unrelated results instead of displaying raw web-search output.

## Render

Build: `pip install -r requirements.txt`

Start: `python app.py`

Required secret: `GROQ_API_KEY`
